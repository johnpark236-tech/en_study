# 매일 일상영어 (안드로이드 PWA)

기초 → 초급 → 중급 → 고급, 4레벨 32과 · 하루 1~2시간 루틴 영어 학습 앱.

## 하루 루틴 (8단계)
복습(간격 반복) → 오늘의 단어 → 핵심 표현 따라 말하기 → 대화 듣기·쉐도잉 → 말하기(음성 인식 채점) → 받아쓰기 → 퀴즈 → 영작·일기

## 폰에 설치하기 (GitHub Pages)
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다.
2. Settings → Pages → Branch: main / root 로 저장.
3. 안드로이드 크롬에서 `https://johnpark236-tech.github.io/en_study/` 접속 → 메뉴(⋮) → **앱 설치 / 홈 화면에 추가**.
   - 설치 후에는 오프라인에서도 열립니다. (마이크 음성 인식은 인터넷 필요)

## 콘텐츠 추가
`data.js`의 `lessons` 배열에 같은 형식으로 과를 추가하면 자동으로 화면·퀴즈·받아쓰기에 반영됩니다.
